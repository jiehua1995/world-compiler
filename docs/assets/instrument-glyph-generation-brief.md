# World Compiler instrument glyph brief

## Purpose

The instrument-glyph family gives future World Compiler tools a shared visual language. Concepts are generated and reviewed in 6×6 contact sheets (36 options), while only selected, production-used glyphs are copied to `public/assets`.

## System

- Square cell and centered silhouette with generous padding.
- Geometric subjects derived from optics, scopes, apertures, signals, prisms, coordinates, data shapes, and compilation.
- Consistent civic-technology / public-observatory tone: precise, calm, and legible at thumbnail size.
- Palette: `#FCA104`, `#2F6DB3`, `#E56C57`, `#5200A6`, `#CDB742`, `#45A6B2`, deep navy, and warm off-white.
- No embedded words, letters, numbers, third-party marks, watermarks, or photorealistic objects.
- Functional interface icons remain deterministic SVG/CSS; generated raster glyphs are illustrative identity assets only.

## Generation prompt

Create exactly 36 distinct geometric public-technology instrument glyph concepts in a precise 6×6 grid. Give every cell equal space and one centered symbol inspired by optics, color perception, data lenses, signal scopes, compilers, prisms, apertures, waveforms, coordinates, and observation devices. Use crisp flat vector-friendly construction, consistent stroke weights and corner logic, and the project palette. Include no text, logos, trademarks, mockup frames, or watermarks.

## First selected glyph

Color Vision Lab uses a single eye/aperture form with segmented palette channels. Its generated source is transparent and carries no accessible meaning by itself; the corresponding tool card supplies the textual name and description.
