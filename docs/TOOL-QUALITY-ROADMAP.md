# 世界编译局｜工具专业化路线图

本路线图建立在当前静态 Astro 工具目录上。目标不是给每张工具页塞更多按钮，而是让每个工作台围绕一个真实任务形成完整闭环：输入 → 检查/预览 → 可解释的结果 → 可控导出/撤销。色觉实验室已先完成多模式配色检查、图片取色、配色生成与预设、对比审查；以下覆盖其余现有工具，并按风险和使用价值安排次序。

## 先合并重复工作流，再扩功能

合并的是用户看到的功能入口和共享工作流，不是把所有逻辑塞进一个巨型控制器。保留现有工具 URL 作为直达入口（可映射到对应工作台页签），迁移期不破坏书签和 README 链接；底层模块仍独立测试。

| 工作台套件 | 收拢的现有工具 | 用户得到的连贯流程 |
|---|---|---|
| **Markdown Studio** | Markdown 文档诊断 + Markdown 表格构造器 | 左侧编辑、右侧实时安全渲染；表格作为插入/编辑组件；同一侧栏查看标题、链接、图片 alt、拼写式结构诊断。 |
| **Text Studio** | 文字工坊 + 文本格式整理器 | 统计、清理、大小写/slug 转换共享输入；操作可选、预览差异、撤销；文本 Diff 保持独立的双文档比较任务。 |
| **Color Studio** | 色觉实验室 + 配色提取台 + 颜色转换 + 渐变 | 颜色方案、格式和渐变共用色板；色觉检查仍是独立模式，直达 URL 保留。 |
| **Image Studio** | 图像工坊 + 图像格式转换 + 图像属性检查 | 同一图片队列进入裁剪/尺寸/编码/属性/元数据清理步骤；安全 SVG 清理保留独立隔离流程。 |
| **PDF Desk** | PDF 整理台 + PDF 文本提取 + 图片转 PDF | 用“整理 / 提取文本 / 创建 PDF”任务页签串起本地文档作业；OCR 保持独立，因为引擎下载、语言包和光栅页识别有不同隐私/资源提示。 |
| **Time Studio** | 时间桥 + 日期计算台 + Cron 计划器 | 日期、时区、时间戳和排程共享 IANA 时区/夏令时控制；各模式仍能单独直达。 |
| **Random & Tokens** | 随机工坊 + Token Lab + UUID 工作台 | 密码、短语、抽样、UUID 使用统一生成历史（仅当前内存）与安全随机说明；不保存生成结果。 |
| **Data Studio 导航组** | JSON 工作台、Schema、JSONPath、YAML/JSON、CSV/JSON、CSV 剖析、数据塑形、Markdown 表格移入 Markdown Studio | 以任务导航串起检查、查询、转换和表格剖析；每种任务保持专属参数与边界，不做一个拥挤的万能表单。 |

### Markdown Studio 的首个专业版本

把当前“点按钮后输出结构报告”的单文本框改成桌面左右两栏、手机可切换“编辑 / 预览”的在线编辑器。编辑时即时渲染；工具栏支持标题、粗体、链接、代码、引用、列表和表格，表格构造器直接插入光标位置。预览提供 Markdown/GFM 表格和任务列表支持、目录跳转、字数/阅读时间、诊断定位、同步滚动开关、复制/下载 `.md`。默认不自动保存；原始 Markdown 不丢失，HTML/脚本不执行，预览外链图片默认不自动请求，链接只在用户主动点击后打开。实现前选定并审查轻量 CommonMark/GFM parser 的许可、包体与安全配置；不手写脆弱的 Markdown 正则渲染器，不在首版加协作、账号、云同步或 AI 改写。

**首个实现项目**：Markdown Studio + 合并表格工具。完成后按 A 的高频顺序逐项推进；套件合并先做导航/共享工作流，避免先动 URL 或移除能力。每批仍限制 1–3 个工作台，并保留旧链接兼容。

**已完成**：Markdown Studio 与 Markdown 表格兼容入口；Text Studio 首版（文字工坊与文本整理器合并、可组合操作、前后对照、撤销/重做、字符/UTF-8 字节/词/行统计）。旧 `/tools/text-format/` 继续直达同一工作台，但目录只保留一张卡片。下一批继续按 A 阶段深化。

## 共同的完成标准

- 中文、英文、德文的静态文案、动态状态、表单标签和导出名称一致；键盘可完成主要流程，手机和明暗主题布局可用。
- 导入与处理默认留在本机内存。需要下载引擎/词表时明确告知并由用户操作；不把内容放入 PWA 缓存、URL、日志或持久存储。
- 每个导出都能预览、说明格式/限制，并避免格式扩展名与实际 MIME 不一致；耗时和大文件工作提供进度、取消与资源上限。
- 结果尽量解释“为什么”，同时清楚区分硬错误、启发式警告和合规/质量结论；不把近似估算包装成认证。
- 每项升级添加纯逻辑单测和真实浏览器流程测试；核心路径覆盖错误输入、取消/重置、跨语言和移动视口。

## 分阶段顺序

### A｜用户高频、可形成完整闭环

1. **对比度透镜**：支持 2–12 色设计令牌/前景-背景组合批量审查；逐项显示 WCAG 2.2 AA/AAA（普通/大字）结果、失败颜色通道与可调候选修正；提供文字、图标、控件状态样例和可分享的本地 HTML/JSON 报告。保留颜色不能作为唯一信息的设计提示。候选值不是自动认证，最终仍需人工检查真实界面。
2. **图像工坊**：完善裁切框和常见比例、锁定宽高比、缩放算法选择、旋转/翻转、透明背景与 JPEG 底色；支持多图队列、逐张参数、输出前后尺寸/体积对照、批量导出。以最大像素、总像素和内存预估阻止浏览器崩溃；动画图片明确只处理首帧。
3. **文字识别台（OCR）**：加旋转/裁切/灰度/阈值预处理、语言模型选择、识别进度与取消、置信度和逐行结果、复制/下载 TXT。PDF 扫描页可从本地 PDF 渲染并按页选取；引擎及语言数据首次下载前解释体积，之后可离线使用。置信度不是准确率保证。
4. **PDF 整理台**：缩略图和拖拽排序、旋转、勾选/范围提取、拆分为多个文件、合并队列、页数/体积预览；操作只写新文件，绝不改源文件。明确表单、书签、批注、数字签名可能无法保留，不承诺压缩或修复损坏文档。
5. **数据塑形台**：增加列类型推断及可编辑覆盖、筛选/排序、删除/重命名/重排列、空值/重复/异常行提示、撤销和转换前后预览；支持 CSV/TSV/JSON 导入导出并报告每一步影响行数。公式注入保护默认开启，用户可见且可控。
6. **JSON 工作台**：结构树与路径定位、折叠/搜索、格式化/压缩、排序键、选中节点导出、JSON Pointer 快速跳转；错误定位显示行列和附近内容。对超大输入限制深度/大小，不运行用户输入的代码或表达式。
7. **文本对照镜**：按行/词/字符比较，忽略空白、大小写或行尾差异，可视化行内改动和统计，左右/统一视图切换，导出 unified diff；编辑任一侧后及时标记结果过期，限制输入量与最长处理时间。
8. **清晰语言仪**：中/英/德分开使用可解释的语言规则，标出长句、术语、被动/复杂结构和数字密度；显示各指标计算方式，支持忽略标题/引用等区域，并给出规则化、可逐条接受的简化建议。短文本或不支持的语言不输出虚假精确分数；不声称理解语义或替代专业编辑。

### B｜专业深度和数据安全细节

9. **编码实验室**：Base64/URL/HTML 转换增加 UTF-8/二进制差异、大小估算、文件分块哈希进度/取消、多格式校验和逐项对齐；始终把内容当数据，不执行、不自动访问解码出的 URL。
10. **二维码工作台**：文本/URL/Wi-Fi/vCard 等有预览的类型模板，纠错等级、边距、前景背景、尺寸和 SVG/PNG 导出；按预览检查最小对比度与静区，并说明过密内容会降低扫码可靠性。暂不加中心 Logo，避免在没有可验证扫描测试前牺牲纠错余量。
11. **随机工坊**：可配置字符集/排除歧义字符/批量生成/复制；支持自定义号码范围、去重和抽样规则，提供随机祝福、提示语和占位文案模板。安全凭据使用 Web Crypto；抽奖只声明随机抽样，不宣称法律/审计级公平。
12. **密码强度检查**：避免只用字符种类推熵；本地检查重复片段、常见模式和词典规则，逐条解释估算假设。任何时刻不发请求、不保存输入、不显示夸张的破解时间承诺；不做在线泄露检查。
13. **CSV 剖析**：明确分隔符/引号/编码设置，样本预览，列类型、缺失/唯一/重复/极值及分布摘要，异常行定位与报告导出。默认不上传、不推断敏感含义；大型文件使用流式读取或清晰限制。
14. **CSV / JSON 桥**：分隔符、引号、换行、空值/数字解析策略可见可调，预览往返损失；表头映射和数组/对象模式切换。保留严格的重复表头、行长校验与公式转义。
15. **Markdown 结构诊断**：作为 Markdown Studio 的侧栏/检查器，补充跳级标题、重复锚点、引用链接、图片 alt、相对链接和孤立引用检查；目录锚点规则可选 GitHub 风格；诊断可定位到编辑行。表格生成并入同一编辑器，不再维护平行的第二个 Markdown 工具页。
16. **正则实验室**：展示命中范围/捕获组、逐项替换预览、命名组和常用表达式片段；所有匹配仍在可终止 Worker 中，有输入/输出上限与取消。解释仅覆盖常见语法子集，不判断任意正则一定安全。
17. **网址工作台**：安全协议/主机/端口拆解、查询参数增删重排、多网址批处理、追踪参数规则预览和可逆清理；IDN 同时显示 Unicode 与 punycode。默认只解析字符串，不探测目标站、不自动跟随链接；危险 scheme 明确拒绝。
18. **单位换算台**：按维度分组、常用收藏、精度/有效位控制、公式和单位定义说明；温度转换标明绝对温标与温差换算区别，数据单位标明 SI/IEC 十进制或二进制。不是专业测量/工程校准器。
19. **随机生成器（Token Lab）**：批量 UUID、可选 UUID v4/v7 与校验、密码长度/字符集模板及熵来源说明，单击复制和一次性清除。仅用 Web Crypto，不提供可预测种子或将 token 存到历史。
20. **文字工坊**：操作链可组合、每步差异预览、撤销/重做、Unicode NFC/NFKC 和换行规则可选；统计字符、字节、行、词并避免误伤组合字符。转换前后始终保留原文。
21. **颜色格式转换**：在既有 HEX/RGB/HSL 基础上增加 alpha、HSV 与 OKLCH（明确颜色空间/浏览器兼容），可复制 CSS、检查对比度并发送到配色工作流；显示色域裁切警告。不把超出 sRGB 的颜色静默截断。
22. **渐变配方台**：多色标、位置编辑、线性/径向和角度/形状、插值方式预览，支持 CSS 导入/解析与导出；边界色标和重复色标可视化。暂不承诺所有旧浏览器的精确渲染一致。

### C｜边界清晰的专用工具

23. **YAML / JSON 转换**：错误行列、缩进/引号/数组风格选项、多文档预览、重复键/锚点风险提示；往返结构比较。不接受 entity 或执行自定义 tag；资源与别名展开设上限。
24. **XML 整理台**：错误定位、命名空间/属性检查、格式化/压缩、XPath 的安全只读有限子集；上传前后结构预览。继续拒绝 DTD/外部实体/网络解析，不插入真实数据。
25. **CSS 工坊**：按规则检查语法、选择器/属性统计、重复声明/无效颜色提示、格式化/压缩差异视图；CSS 输入不注入工作台页面，不加载外部 import。
26. **JSON Schema 推断器**：合并多个样本而不是只看一条，控制 required/null/enum/额外字段策略，验证样例并列出路径级问题；展示 Schema 版本和推断限制，不推断未观测数据必然成立。
27. **JSONPath 查询台**：继续提供可解释的受限语法和命中路径；为通配符结果增加路径/类型/数量统计、复制选中结果。过滤器仅在引入有界安全解析器及测试后考虑，绝不 eval。
28. **进制转换台**：分组显示、字节/位宽和二进制补码作为显式模式，溢出行为可见；整数任意精度保持默认。小数/浮点只有在舍入规则和测试明确定义后才添加。
29. **Unicode 检视器**：字素簇与码位并排、组合字符/ZWJ/变体选择符检查、规范化前后差异、UTF-8/UTF-16 长度和 JS/CSS/JSON 转义。通用名称数据库按需评估体积，不打包巨大不必要资产。
30. **Robots.txt 检查器**：分组边界、通配符、Allow/Disallow 冲突与 Sitemap 语法的分层诊断，提供按用户代理模拟路径的本地测试；规则差异按常见爬虫分开说明。不抓取站点，也不声称所有爬虫解释完全相同。
31. **SVG 安全整理**：安全预览、移除前后字节/元素差异、尺寸与 viewBox 修复、可勾选的安全优化和批量操作；维护脚本、事件、外部引用清除的默认安全边界。必须在隔离上下文预览，不把未清洗 SVG 注入 DOM。
32. **图像格式转换**：批量队列、可用编码器探测、尺寸/质量/透明通道设置、逐项体积比较和失败恢复；支持格式由运行浏览器实际解码/编码能力决定，绝不宣称“万能格式”。
33. **图标标记工坊（Favicon）**：可编辑矢量标记、浅/深背景预览、多尺寸 PNG/SVG 变体与 HTML/PWA link 片段，导出前查看每种变体。若生成 ICO/多文件包需单独验证字节格式，不只改扩展名。
34. **图像属性检查**：增加可选 EXIF 基本字段与 GPS 隐私提醒、时间/方向解释、元数据清理后副本导出；默认不展示/分享 GPS，清理前显示将移除的字段。格式解析需有样例和畸形输入保护。
35. **文本格式整理器**：操作选择、预览差异、逐行规则、大小写本地化、slug 字符集策略和撤销；不把德国 ß、土耳其语 I 等 Unicode 本地化行为混作英文规则。
36. **Markdown 表格构造器**：列对齐、空值策略、复制/导出、多种分隔符输入、表头/列数校验和预览；不执行公式、不悄悄吞掉多余单元格。
37. **音频实验室**：波形与时间/样本精确裁切、左右声道/峰值/RMS 显示、淡入淡出、增益预览、取消和导出体积预估；格式与采样率限制说清楚。先聚焦可验证的剪辑，不承诺语音增强/降噪或专业母带效果。
38. **流媒体工作室（M3U8）**：强化清单树、变体/分辨率/时长/分段统计、逐段进度与失败重试、取消/内存估算、明确下载前确认。范围仍限用户有权访问的公开、CORS 允许、未加密 VOD MPEG-TS；不绕过 DRM/登录/防盗链、不抓取直播、不伪称 MP4 转码。
39. **PDF 文本提取**：页级预览/勾选/范围、阅读顺序提示、保留分页与基本段落、文本层为空时推荐 OCR 工作流并可将页面交给本机 OCR；导出 TXT/JSON。文字层提取和 OCR 识别分开标注，不保证复杂版面阅读顺序。
40. **图片转 PDF**：缩略图拖拽排序、旋转、页尺寸/方向/边距/填充和背景色、每页图像质量与输出大小预估；创建前预览分页。源图不改动，设置清晰内存和 PDF 页数上限。
41. **Cron 计划器**：常见表达式预设、逐字段解释、指定时区和夏令时转换附近的执行时间预览、下一次/前后 N 次结果；错误标在具体字段。默认五段语法，扩展语法在实现前标清兼容来源，不能静默按 UTC 假设。
42. **IPv4 子网计算器**：子网拆分规划、地址块对齐、连续网段/可用主机数和点对点边界提示，二进制位可视化；支持多网段规划但不扫描网络。IPv6 作为独立后续工作，需先有全面边界测试。
43. **日期计算台**：日/周/月区间计算、包含/不包含端点说明、工作日偏移与用户提供假日日历；严格区分 date-only 和带时区瞬间，避免 DST/月底自动进位带来惊讶。
44. **摘要与校验实验室**：文件拖放队列、SHA 算法说明、进度/取消、大小限制、两个文件/文本摘要比较和标准 checksum 清单导入导出；对同文件、空文件和超限场景单测。不把哈希相同说成来源可信或文件安全。
45. **UUID 工作台**：批量生成、v4/v7 选择、校验版本/variant、排序与时间字段说明；仅用安全随机源，明确 UUID 不是身份认证或密码。暂不生成含 MAC 地址/机器标识的旧式版本。
46. **HTML 实体转换**：完整命名实体覆盖的体积评估、十进制/十六进制码位切换、仅选中片段转换、格式化/原文对照；畸形引用处理规则可见。输出只作为文本，不渲染为可执行 HTML。
47. **配色提取台（独立工具）**：从多张本地图片分别提取并比较主色、调色板去重/排序、色板合并与手动调整、HEX/CSS/JSON 导出；逐个采样结果能回到源图定位。复用色觉实验室的调色板/对比逻辑，避免两套行为不一致。
48. **时间桥**：Unix 秒/毫秒检测与显式确认、UTC/本地/多个 IANA 时区并排、日期格式解析预览、DST 重复/不存在时刻警告、会议时间区间转换；时区数据库由浏览器 Intl 提供，显示设备环境差异，不做含糊猜测。

## 每一批的交付

每次只升级 1–3 个关系紧密的工具，先补针对核心逻辑的失败测试，再实现 UI/交互、补三语和可访问性、跑目标浏览器流程，最后运行 `npm run verify`。达到完成标准后才进入下一批；在每个工具页面和 README 中同步它的真实边界。优先批次建议按 A 的顺序；B、C 内部按用户反馈、维护成本和安全风险滚动调整，不先引入需要服务端、账户、付费 API 或远程处理的功能。

## 不纳入本轮路线

暂不加账号/云端同步、遥测、远程 AI 重写、在线密码泄露查询、网站爬取、DRM/登录绕过、未经验证的“万能”格式转换、医疗/法律/财务认证结论。若未来提出，会先单独评估隐私、授权和可验证性。
